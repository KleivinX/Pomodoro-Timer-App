1. PROJECT OVERVIEW
================================================================================

SaladTimer is a productivity and self-improvement web application built around
the Pomodoro Technique. It is a Progressive Web App (PWA) that can be installed
on devices for offline use. The app tagline is:

  "Productivity & Self-Improvement"

The app has three main tabs/sections:
  1. Timer   - A full Pomodoro timer with focus sessions and breaks
  2. Habits  - A circular habit tracker for daily goals
  3. Lock-In - A GitHub-style contribution heatmap calendar tracking consistency

The app is designed with a glassmorphism aesthetic, smooth animations, and
full dark/light theme support via next-themes.

4. DESIGN AESTHETIC & VISUAL EFFECTS
================================================================================

Glassmorphism:
  - .glass class: backdrop-filter blur(20px), semi-transparent bg, subtle border
  - .glass-smooth class: backdrop-filter blur(12px), lighter variant with hover
  - Dark mode variants with adjusted opacity
  - Used on cards, panels, and the tab navigation

Custom Animations:
  - confetti: Particles fly upward with rotation and fade
  - float: Gentle 5px vertical bobbing (4s infinite, used on timer ring)
  - slide-in-up: 10px upward slide with fade-in (0.3s)

Button Effects:
  - .btn-smooth: 1px upward hover lift, instant press snap-back
  - Hover scale effects (scale-110 on timer controls)
  - Rotation on hover for certain icons (reset button spins 180deg)

Transitions:
  - Global 150ms ease-out on color, background, border, opacity, transform
  - Smooth scrolling enabled on html element

Custom Scrollbar:
  - 8px width
  - Muted track, muted-foreground thumb
  - Rounded 4px thumb with hover darkening

Focus States:
  - 2px solid ring colour, 2px offset
  - 0.2s ease-in-out transition

5. FEATURES & COMPONENTS
================================================================================

--- TAB 1: POMODORO TIMER ---

Component: PomodoroTimer (pomodoro-timer.tsx)
  Main orchestrator with state management for the timer.

Sub-components:
  - ModeSelector (mode-selector.tsx)
    - 4 modes: Pomodoro (25min), Short Break (5min), Long Break (15min), Custom
    - Each mode has a distinct colour and emoji
    - Custom mode has editable minutes/seconds input
    - Disabled during running state

  - TimerDisplay (timer-display.tsx)
    - SVG circular progress ring (radius 120, strokeWidth 8)
    - Large monospace countdown display (text-6xl)
    - Status indicator dot (green=running, yellow=paused, grey=idle)
    - Floating animation when idle
    - Colour changes per mode

  - Controls (controls.tsx)
    - Large round play/pause button (w-20 h-20)
    - Smaller round reset button (w-16 h-16)
    - Glow effect when running
    - Reset icon spins 180deg on hover

  - SessionTracker (session-tracker.tsx)
    - 8 dots showing completed sessions
    - Tracks sessions per page load (not persisted)
    - Celebrates every 4 sessions (full cycle)

  - TaskManager (task-manager.tsx)
    - Collapsible task list in the side panel
    - Add/complete/delete tasks
    - Completion counter badge
    - Tasks recorded to activity tracker for Lock-In Calendar
    - Hover-reveal delete button
    - Animated green checkmark

  - Notes (notes.tsx)
    - Collapsible notes manager in the side panel
    - Create, edit, delete, download notes as .txt files
    - Persisted in localStorage (key: pomodoro-notes-multiple)
    - Notes recorded as "reflection" for Lock-In Calendar
    - Shows time-relative dates ("5m ago", "2h ago")

  - YouTubeWidget (youtube-widget.tsx)
    - Floating music player (fixed bottom-left)
    - Red circular toggle button with music icon
    - Minimizable mini-player view
    - Embedded YouTube iframe player
    - Pre-loaded playlists: Lo-fi Focus, Rain Sounds, Piano Focus, Nature Sounds
    - Custom YouTube URL support
    - Volume slider, play/pause, skip controls
    - Fallback UI when player is blocked (opens YouTube Music)
    - 8-second load timeout detection

  - ConfettiEffect (confetti-effect.tsx)
    - 50 particles with random positions and delays
    - 6 colours, flies upward with rotation
    - Triggered on Pomodoro session completion
    - Auto-dismisses after 3 seconds

Timer Behaviour:
  - Uses Date.now() for accurate timing (not setInterval counting)
  - 200ms interval updates
  - Handles tab visibility changes (recalculates on return)
  - Auto-cycles: Pomodoro -> Short Break (or Long Break every 4th)
  - Sound effects: Start tick (600Hz sine, 0.15s) and completion ticking
    (20 alternating 440Hz/350Hz tones over 10 seconds)

--- TAB 2: HABIT TRACKER ---

Component: HabitTracker (habit-tracker.tsx)
  - Circular SVG visualisation (viewBox 400x400)
  - Concentric rings for each habit, segmented by days of month
  - 300-degree arc with 2-degree gaps between segments
  - Day labels rotated around the outside
  - Centre displays total completion percentage
  - Month navigation (prev/next)
  - Up to 10 habits with 9 colour options
  - Per-habit completion rate calculation
  - Stats: Total Check-ins, Goals on Track (80%+ threshold)
  - Data persisted in localStorage per month-year
  - Click segments to toggle day completion

--- TAB 3: LOCK-IN CALENDAR ---

Component: LockInCalendar (lock-in-calendar.tsx)
  - GitHub-style contribution heatmap
  - Three views: Month, 90 Days, Year (52 weeks)
  - 4 intensity levels: none, partial, locked, deep
  - Grace Day support (yellow, max 2 per month)
  - Hover tooltips with daily details
  - Stats cards: Total Locked-In Days, Current Streak, Longest Streak,
    Avg Days Per Week, Best Week, Consistency Engine (progress bar to 365)

Activity Tracking Logic (lib/activity-tracker.ts):
  - Lock-In Level calculation:
    - "none": No activity
    - "partial": Only reflection completed
    - "locked": 1+ focus sessions OR 1+ tasks completed
    - "deep": 2+ focus sessions OR (focus + task + reflection)
  - Records: Focus sessions, task completions, reflections
  - Data persisted in localStorage (key: saladtimer-activities)

================================================================================
8. DATA STORAGE
================================================================================

All data is stored in localStorage (client-side only, no backend database):

  - "habits-{month}-{year}": Habit data per month (array of Habit objects)
  - "pomodoro-notes-multiple": Notes array (title, content, timestamps)
  - "saladtimer-activities": Lock-In Calendar activity data

No authentication, no server-side storage, no API routes.
Tasks are session-only (not persisted across page reloads).
